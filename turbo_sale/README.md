# 🚀 Turbo Sale
## Overview
Turbo Sale is a smart, one-click sales processing app for Odoo that automates the full sales flow:

### Quotation Confirmation ✅

### Delivery Validation ✅

### Stock Check with Force Delivery Prompt ✅

### Invoice Generation ✅

### Payment Prompt ✅

This app is designed to save time and simplify the sales process for managers by handling all key steps in a single action.

Features
🛒 Turbo Confirm Button: One-click to confirm sales, delivery, invoice, and payment.

📦 Automatic Stock Check: Prompts the user if any product is out of stock.

🚚 Force Delivery Option: User can choose to proceed with force delivery for insufficient stock.

🧾 Invoice Creation: Automatically creates and posts invoices.

💵 Payment Prompt: Opens the payment registration wizard immediately after invoice confirmation.

🔒 User Restriction: Button only visible to Sales Managers.

Installation
Download the turbo_sale.zip file.

Go to Apps > Upload a module in your Odoo instance.

Upload the zip file and install the module.

Usage
Open a Quotation.

Click the Turbo Confirm button.

If stock is insufficient, a pop-up will appear asking if you want to force the delivery.

After delivery validation, the payment prompt will automatically open.

Security
The Turbo Confirm button is only visible to users with Sales Manager access rights.
